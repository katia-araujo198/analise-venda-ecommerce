# 📊 Análise Exploratória de Dados de E-commerce (EDA)

Este repositório contém um projeto prático de **Ciência de Dados** focado na análise exploratória de um conjunto de dados de vendas de e-commerce.

## 🚀 Tecnologias Utilizadas
* Python 3.x
* Pandas, NumPy, Matplotlib e Seaborn
* Jupyter Notebook

## 📈 Principais Etapas
1. Limpeza e Tratamento de Dados.
2. Análise Estatística Descritiva.
3. Geração de Gráficos de Faturamento e Tendências.
